# JIDU6401: install OpenWrt

The JIDU6401 is a Sercomm-built MediaTek `6j01` router. OpenWrt supports it
officially from 25.12.6. This page is the flashing guide for that model: the
exact files, the two ways in, and what is different from its siblings. The
shared reasoning is in [Installing OpenWrt by
hand](../../OPENWRT.md#mediatek-6j01-jidu-6101--6201--6401--6601--6701).

> [!WARNING]
> Flashing replaces the stock firmware permanently. Back up first. Use 25.12.6
> or newer: older 25.12 builds could silently fail to write the SPI-NAND.

## What is different on the JIDU6401

Official files are shared with the JIDU6J01 build, so the names use `jidu6j01`.

This is a Sercomm build: stock releases carry the `SRCMJIO_` prefix, and the
MFG partition uses Sercomm's layout rather than plain `KEY=VALUE` lines.

Its MAC address is a binary value at offset `0x20` of MFG.

A UART pin photo is published for this model, so route A is the easy one here.

## Before you start

- [ ] `./flash.sh backup` has finished. The folder has `uboot_credentials.env`
  and one `.bin` per partition.
- [ ] The official image pair for this model, from 25.12.6 or newer.
- [ ] A UART adapter at 3.3 V and a TFTP server for route A.
- [ ] Root SSH works, if you plan to use route B: `ssh -i ~/.ssh/idu_rsa root@192.168.31.1`.
- [ ] An Ethernet cable. Do not flash over Wi-Fi.

## Route A: UART and TFTP (official)

This is the install OpenWrt documents. It works on all four shared `jidu6j01` models.

### 1. Download and rename the files

Get the pair from the [firmware selector](https://firmware-selector.openwrt.org/).
For this model they are:

```
openwrt-<version>-mediatek-filogic-jiorouter_ax6000-jidu6j01-initramfs-kernel.bin
openwrt-<version>-mediatek-filogic-jiorouter_ax6000-jidu6j01-squashfs-sysupgrade.bin
```

Rename them so the commands below stay short:

```sh
mv openwrt-*-jidu6j01-initramfs-kernel.bin initramfs.bin
mv openwrt-*-jidu6j01-squashfs-sysupgrade.bin sysupgrade.bin
```

### 2. Prepare the TFTP server and UART

Put `initramfs.bin` in the root of a TFTP server and give your PC the address
`192.168.1.2` on the Ethernet interface you will use. Connect the UART adapter
at **115200 8N1** and open the console.

### 3. Stop the boot

Power on the router. At the boot menu, select **Failsafe Mode**, then press
`Ctrl-C` to interrupt and reach the U-Boot prompt. Log in with the username and password in `uboot_credentials.env` from your backup.

### 4. Boot the initramfs

At the U-Boot prompt:

```text
setenv ipaddr 192.168.1.1
setenv serverip 192.168.1.2
tftpboot 0x46000000 initramfs.bin
fdt addr $(fdtcontroladdr)
fdt rm /signature
bootm
```

`$(fdtcontroladdr)` is typed literally. `fdt rm /signature` removes the vendor
signature node, which is what lets the unsigned OpenWrt image boot.

Nothing is written to the flash in this step. If it fails, power-cycle and the
stock system is still there.

### 5. Install the sysupgrade

After about a minute the initramfs answers at `192.168.1.1`. From your PC, in
the folder with `sysupgrade.bin`:

```sh
scp -O sysupgrade.bin root@192.168.1.1:/tmp/
ssh root@192.168.1.1 "sysupgrade /tmp/sysupgrade.bin"
```

`unknown option -- O` means your `scp` is old; drop `-O` and retry. If SSH is
refused, open `http://192.168.1.1` and use **System → Backup / Flash Firmware →
Flash image…** with `sysupgrade.bin`. Do not tick *Keep settings*.

It writes the flash and reboots. Wait until it answers at `192.168.1.1`, then
set a root password.

## Route B: SSH shortcut (all five 6j01 models)

This is the path this project documented before official support. It writes a
community `factory.ubi` to the spare slot, boots it, then installs the
sysupgrade from the same folder. It ends on that build, not necessarily the
current official release. Use route A if you want the official image.

### 1. Confirm the layout

On the router:

```sh
ssh -i ~/.ssh/idu_rsa root@192.168.31.1
cat /proc/mtd
```

Expect `mtd6` to be `ubi2`, the vendor's spare slot. If it does not match,
stop and compare it with `partitions.txt` in your backup.

### 2. Send the community stage 1

From your PC, in the folder with the community images:

```sh
scp -O openwrt-mediatek-filogic-jiorouter_ax6000-jidu6j01-initramfs-factory.ubi \
    root@192.168.31.1:/tmp/
```

### 3. Write it and set the boot variables

```sh
ubidetach -m 6
ubiformat /dev/mtd6 -y -f /tmp/openwrt-mediatek-filogic-jiorouter_ax6000-jidu6j01-initramfs-factory.ubi

fw_setenv bootcmd 'ubi detach; ubi part ubi2; ubi read 46000000 kernel; fdt addr $(fdtcontroladdr); fdt rm /signature; bootm 0x46000000'
fw_setenv dual_boot.current_slot 1
fw_setenv dual_boot.slot_0_invalid 1
fw_setenv dual_boot.slot_1_invalid 1
fw_setenv ipaddr
```

**Point of no return** for the stock system on `mtd6`. Keep the single quotes:
`$(fdtcontroladdr)` must reach U-Boot literally.

### 4. Boot the temporary system

```sh
reboot
```

Wait about a minute, then:

```sh
ssh root@192.168.1.1
```

### 5. Install the sysupgrade

From your PC:

```sh
scp -O openwrt-mediatek-filogic-jiorouter_ax6000-jidu6j01-squashfs-sysupgrade.bin \
    root@192.168.1.1:/tmp/
ssh root@192.168.1.1 "sysupgrade /tmp/openwrt-mediatek-filogic-jiorouter_ax6000-jidu6j01-squashfs-sysupgrade.bin"
```

It reboots. Wait for `192.168.1.1`, then set a root password.


## If it goes wrong

- **TFTP times out:** check the PC address (`192.168.1.2`), the TFTP root, the
  firewall, and that the file is named exactly `initramfs.bin`.
- **`Bad FIT` or a signature error:** `fdt rm /signature` was missed, or
  `$(fdtcontroladdr)` was expanded by your shell. Type it literally.
- **No UART output:** check 3.3 V, TX/RX crossing, and 115200 8N1.
- **Sysupgrade fails:** do not power off halfway. If the flash was not touched,
  power-cycle back to stock. If it was, restore from the backup over UART.
- **UART pins:** A pin photo is published for this model, linked above.
